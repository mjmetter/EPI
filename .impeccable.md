## Design Context

### Users
Mixed audience sharing one artifact: C-suite executives scanning for red flags in a 10-minute board meeting, and engineering directors doing monthly trend analysis and drilldown. The report must work at both scan-speed (immediate signal: score, band, direction) and deep-read (metric breakdowns, repo comparisons, AI adoption signals).

### Brand Personality
Authoritative, dense, precise. No warmth, no approachability — this is a performance instrument, not a tool for a friendly experience. The report should feel like something produced by a serious institution, not a dashboard generator.

### Aesthetic Direction
**Precision instrument.** Think Bloomberg terminal, aviation instrument panel, or a financial briefing document. Dense but structured. Every pixel earns its place. No decoration.

**Theme**: Dark. Board meetings, director reviews — viewing context is professional, often projected on screens.

**Color palette**: Deep charcoal (warm near-black) + amber/gold accent. NOT the current navy + indigo which is the AI-design monoculture. The amber accent reads as premium and decisive — Bloomberg energy. Traffic-light band colors (green/amber/red) are functional, retained but refined via OKLCH.

**Typography**:
- UI text + labels: **Barlow Condensed** (600, 700) — condensed grotesque, authority through compression, maximum information density
- Body + table text: **Barlow** (400, 500) — same family, opens up for readability
- Numeric values + scores: **Azeret Mono** — tabular monospace with a distinctive technical character, not the usual IBM/JetBrains

**Layout**: No rounded hero cards. No gradient backgrounds on big numbers. No box shadows. Sharp 1px borders. Dense tabular grids. Structure communicates authority — the data does the work.

### Design Principles
1. **Signal before decoration** — the score, band, and direction should be readable in 3 seconds. Remove anything that competes with that.
2. **Density earns trust** — board-level stakeholders trust data-dense reports more than spacious "designed" dashboards. Compression is a feature.
3. **Functional color only** — amber accent for interactive/current-period highlights; green/amber/red strictly for band encoding. No decorative use of color.
4. **Typography does the work** — hierarchy through weight and condensed width, not through rounded containers and gradients.
5. **Authoritative structure** — tabular grids and consistent column alignment over heterogeneous card arrangements.

### Anti-references
- The current dark navy (#0f172a) + indigo (#818cf8) + rounded-corner cards
- Glowing "all-elite shimmer" animations
- Gradient-filled hero metric numbers
- Generic admin SaaS dashboards (Grafana, Datadog aesthetic)
